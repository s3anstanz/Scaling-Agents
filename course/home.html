The project

Port Kestrel to TypeScript

Kestrel is a made-up open-source image-processing library written in Python. The full library has about 240 modules. Your job, from the first lesson to the last, is to move it to TypeScript without changing what any function does.

A migration is a good teacher. It starts small enough for one agent, it has real dependencies between pieces, and the tests tell you exactly when a piece is right. At 240 modules, it's also big enough that a hundred agents is a real question rather than a stunt.

How each lesson works

Read, predict, then run it

  • Short parts that build one idea at a time, from novice to expert.
  • Predict-then-reveal prompts, multiple choice and make-the-call exercises. Every answer explains itself.
  • Diagrams you can step through, so you see a loop or a graph run.
  • A lab in Claude Code against your own copy of Kestrel, with copy buttons and an estimated cost.

Thread one · all four weeks

Loop engineering

Every agent is a loop: look, act, check, repeat. You will design when a loop stops, what it can spend, what counts as done, and how loops between agents (write, review, fix) settle instead of bouncing forever. At scale, loops become retries, circuit breakers and budgets.

Thread two · all four weeks

Graph engineering

Every team is a graph: agents are the nodes, handoffs are the edges. You will learn the shapes (chain, diamond, double diamond, tree, dependency graph, cycle), when each one fits, and how the shape of the work sets how many agents can help at once.
